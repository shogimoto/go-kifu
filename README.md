# Go Kifu

Minimalistische Web-App, um Go-Partien (19×19) am Brett mitzuschreiben und als SGF zu kopieren.

**App öffnen:** https://shogimoto.github.io/go-kifu/

- Tippen setzt einen Stein, Farben wechseln automatisch
- Schlagen und Ko werden automatisch berücksichtigt
- Letzten Stein antippen nimmt den Zug zurück
- Passen, Rückgängig, neue Partie
- SGF mit japanischen Regeln und 6,5 Komi in die Zwischenablage kopieren, z. B. für AI Sensei
- Funktioniert offline und lässt sich über das Browsermenü auf dem Startbildschirm installieren

Die Partie wird nur im eigenen Browser gespeichert.
